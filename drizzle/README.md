# Drizzle Migration Scripts

This directory contains database migration scripts generated by Drizzle Kit.

## Usage

### Generate Migrations
```bash
npm run db:generate
# or
pnpm db:generate
```

### Push Schema Changes (Development)
```bash
npm run db:push
# or
pnpm db:push
```

### Apply Migrations to Database
```bash
npm run db:migrate
# or
pnpm db:migrate
```

### Drop All Tables
```bash
npm run db:drop
# or
pnpm db:drop
```

### Studio (Visual Database Manager)
```bash
npm run db:studio
# or
pnpm db:studio
```

## Migration Files

Generated migration files will be placed in this directory with timestamps.
